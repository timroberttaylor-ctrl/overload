# Exercise illustrations

The images in this folder are adapted from the **Everkinetic** open exercise data set
(<https://github.com/everkinetic/data>, originally everkinetic.com by Greg Priday),
licensed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**:
<https://creativecommons.org/licenses/by-sa/4.0/>.

Changes made: cropped to a shared frame, resized, and converted from black-on-white to
transparent line art so the app can tint them. These adapted images are shared under the
same licence (CC BY-SA 4.0). The licence covers these image files only, not the app code.
